# Book Library Management System

A full-stack web application designed for cataloging books, tracking lending cycles, managing borrower records, and streamlining library administration.

## Live Application

- Live Frontend: https://booklibrarysystem11.netlify.app/
- Backend API: https://book-library-management-system-mr4d.onrender.com
- GitHub Repository: https://github.com/DikshitaDA/book-library-management-system/

## Tech Stack

- Frontend: React.js, Vite, CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Hosting: Netlify for Frontend, Render for Backend

## Features

- Full Catalog CRUD: Add new book entries, edit details, update stock counts, and delete titles.
- Search and Filter: Find books by title, author, or category.
- Lending Tracking: Record borrowed status and user issue dates.
- Decoupled Architecture: RESTful API connected via environment variables.

## Local Setup

1. Clone the repository:
git clone https://github.com/DikshitaDA/book-library-managem.git
cd book-library-managem

2. Backend Setup:
cd backend
npm install
node server.js

3. Frontend Setup:
cd ../frontend
npm install
npm run dev
